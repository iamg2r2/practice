Problem

Write a C++ program with overloaded functions named area().
  1. Calculate the area of a square using its side.
  2. Calculate the area of a rectangle using length and breadth.
  3. Display both results with suitable labels.

Problem

  1. Use a constructor to initialise the book details.

  3. Display all the details clearly.

04Employee Pay DetailsInheritance⌄

Problem

Create a base class Employee with an employee name and basic salary. Derive a class PaySlip.
  1. Read the employee name and basic salary.
  2. Calculate an allowance equal to 10% of basic salary.
  3. Display the name, basic salary, allowance, and total pay.
Remember
  • Keep common employee details in the base class.
  • Show how the derived class uses inherited data.

Problem

  1. Read two integers.
  2. Pass their addresses to a swapping function.
  3. Display the values before and after swapping.

Problem

  1. Read and display the six marks.
  2. Calculate the total and average marks.

07Stack of IntegersStack⌄

Problem

Implement a stack of integers using an array.
  1. Provide options to push an element, pop an element, and display the stack.
  2. Display a message when the stack is full.
  3. Display a message when attempting to pop from an empty stack.
Check yourself
  • Use a top variable.

08Queue of Customer NumbersQueue⌄

Problem

Implement a simple queue of integers using an array.
  1. Provide options to insert an element, delete an element, and display the queue.
  2. Handle queue-full and queue-empty conditions.
  3. Display the elements in queue order.
Check yourself
  • Track the front and rear positions.

09Search for a NumberArrays⌄

Problem

Write a C++ program to store eight integers in an array and search for a value entered by the user.
  1. Read and display the eight integers.
  2. Ask the user to enter the number to search for.
  3. Use linear search and display whether the number was found.
